# Samandargram

A terminal-based Telegram client built with Python, Telethon, and Textual.

## Features

- Telegram chats, groups, channels, and bots
- Message search
- Media downloads
- Terminal user interface

## Requirements

- Python 3
- Telegram account
- Telegram API credentials

## Run from source

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python samandargram.py
